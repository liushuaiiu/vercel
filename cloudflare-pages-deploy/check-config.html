📝 配置说明

需要确保三个地方的密钥一致：

  1. config.js（前端配置文件）
    • API_KEY：用于 Cloudflare Workers 认证（Authorization: Bearer）
    • PROXY_TOKEN：用于 Vercel 代理认证（X-Proxy-Token）
  2. Vercel 环境变量（代理服务器）
    • PROXY_TOKEN：必须与 config.js 中的 PROXY_TOKEN 完全一致
  3. Cloudflare Workers 环境变量（后端 API）
    • API_KEY：必须与 config.js 中的 API_KEY 完全一致
